# Summarize

帮助研究者真正理解并尽可能复现论文。

## 基本原则

1. **先从第一性原理重建问题。** 先说清系统、研究对象、关键变量和作者究竟想回答什么，再谈结论。
2. **复现推导/方法链。** 找出承上启下的关键方程或关键步骤，说明每一步用了什么定义、假设、近似或条件。必要时给出短的 reader derivation/check，但必须标注“读者推导/检查”，不能伪装成原文内容。
3. **不要全是文字。** 至少给出关键公式/模型、近似条件、尺度/极限检查或可复现步骤；符号沿用原文。
4. **文字精炼。** 少写“本文研究了……结果表明……”套话。优先回答“为什么”“靠什么成立”“在什么条件下成立”“怎么验证”。
5. **机制要直观。** 用大家听得懂的语言解释机制：什么在被增强/抑制、如何互相影响、随参数怎样变化。不牺牲准确性。
6. **证据优先。** 重要结论带 `Sec.` / `Eq.` / `Fig.` / `Table` 或方法定位。无法从正文确认的数值、公式、图表或引用绝不补造。
7. **区分证据层级。** 明确区分 exact relation、controlled approximation、numerical result、measurement、fit/inference 和 interpretation。
8. **补充材料是母文章的证据附件。** 指出它补充了哪些推导、控制实验、校准、收敛或复现细节，可以融合母文章和补充材料来丰富对问题的理解。

## 关键分析

先判断论文更接近 theory / experiment / simulation / hybrid 及其学科，只做与论文相关的检查：

- **尺度与适用区间**：时间、长度、规模、浓度/剂量、温度、数量级或关键无量纲参数；指出结果不能外推到哪里。
- **模型/方法链**：只选真正承载论证的公式或方法步骤。说明从上一步到下一步做了什么、哪些项被忽略、为什么可以忽略、最终连到哪个可观测结果。
- **假设与近似清单**：`假设/近似 | 条件 | 影响的结果 | 定位`。区分严格恒等式、受控近似、经验近似、数值截断和拟合。
- **sanity check**（信息足够时）：量纲/单位检查、参数增减趋势、特殊情形、极限情形。若是自己的检查，明确标注。
- **实验 ↔ 理论/模拟桥梁**：哪些量直接测量、哪些拟合/反演/校准；参数哪些固定、哪些来自数据、哪些自由拟合；关键误差与系统不确定度。
- **复现路径**：理论/建模给模型、方程、初边值/超参、数值方法；实验/实测给几何、样本、装置、标定、数据处理和关键对照实验。

## 默认输出

```text
# {title} — 研究笔记

## 一句话结论
用 1–2 句回答“这篇论文真正改变了什么认识”。

## 问题与机制
用直观语言说明研究对象、核心矛盾、机制与适用区间。

## 关键推导 / 方法链
给出少量真正关键的方法或方程，并解释假设、近似与意义。不要罗列所有公式。

## 主要结果
只保留最重要的 3–6 个结果；数值、图表和方程尽量给定位。

## 假设、局限与可信区间
指出哪些结论是严格的，哪些依赖近似、拟合、有限样本/尺寸或系统误差。

## 如何复现
列出复现核心结果真正需要的模型、参数、数据/装置、设置和检查项。

## 值得引用的地方
给出 2–4 个精准的引用场景，不编造原文句子。

## 关键词
3–8 个规范化关键词。

## 深读时追加
仅当用户明确要求精读，或核心结论无法用上述结构讲清时，再追加：

- `symbol/变量 | 含义 | 单位/量纲 | measured/defined/fitted | locator`
- `claim | evidence | evidence type | qualification`
- 3–8 个优先级明确的 reader verification / reproduction tasks

最终目标：让读者既知道“作者说了什么”，更知道“为什么会这样、步骤如何连起来、在哪些条件下成立、自己怎样复现或验证”。
```
