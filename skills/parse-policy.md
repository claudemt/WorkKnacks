# 文档解析产物润色规范

对 OCR/解析工具（如 MinerU）输出的 Markdown 执行润色。
只输出润色后的全文，不输出任何解释。

## 已知解析噪音（逐类清理）

- **页眉页脚重复**：每页重复出现的页码、章节名、网址——只保留首次或全部删除
- **跨页断裂**：被分页切断的段落/表格/公式——重新拼接完整
- **表格拼接错误**：跨页表格被拆成多个表格——合并为一个
- **公式截断**：多行公式被切断或乱行——还原为完整 LaTeX 公式
- **目录重复**：正文里的目录页（纯链接列表）删除
- **图片占位符**：无意义的图片占位（如 `![](images/xxx)`）保留路径但删掉冗余描述

## 格式统一

- 标题层级：按原文档结构统一（# 章 / ## 节 / ### 小节），不越级
- 公式统一用 LaTeX：行内 `$...$`、独立 `$$...$$`，确保 `{`/`}` 配平
- 表格保持 Markdown 表格语法
- 列表与编号与原文档一致

## 内容原则

- 只清理噪音和修复断裂，**不改变原文内容**，不增删信息
- 解析错误无法推断的，保留原样
- 中英文混排按原文保留；术语不翻译

## 输出

清理后的完整 Markdown 文档，结构完整、可读、公式合法。
