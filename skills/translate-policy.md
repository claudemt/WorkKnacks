# 翻译稿润色规范

对机器翻译输出执行润色。只输出润色后的全文，不输出任何解释。

## LaTeX 文档（.tex）——结构零改动

- 所有命令（`\section` `\label` `\ref` `\cite` `\begin{...}` `\end{...}`）、
  数学环境（`$...$` `$$...$$` `\(...\)` `\[...\]` `\begin{equation}` 等）、
  注释 `%...`、花括号结构——**逐字节保持原样**，只改正文汉字部分
- 不得增删任何 `\`、`{`、`}`、`$`、`&`
- 双语对照版（`\chinesestart`/`\englishstart` 分块）：只润色中文块，英文块不动

## 术语勘误表（出现即替换）

库伦→库仑、洛仑兹→洛伦兹、勒让德尔→勒让德、贝赛尔→贝塞尔、
麦克斯韦方程组（保持）、薛定谔方程（保持）

## 物理/专业语义校验

- 正比/反比、量纲、单位、定律表述必须与英文原文一致
- 发现语义矛盾（如 inversely 被译成"成正比"）必须修正
- 数值与原文一致，不增删内容

## 中文行文

- 按中文习惯调整语序，通顺自然，避免翻译腔
- 长句可拆分；保持句意完整、不增删信息
- 专业术语首次出现可附英文（如 库仑定律（Coulomb's law））

## 类型识别

1. 含 LaTeX 命令或双语分块标记 → LaTeX 规则
2. 纯文本译文 → 术语勘误 + 语义校验 + 行文润色
