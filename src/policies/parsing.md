# 文献解析内部规范

这是 WorkKnacks 的程序内部策略。目标是把 PDF 恢复成可阅读、翻译、引用和编辑的 LaTeX 工程。

## 结构
- 唯一入口 `main.tex`；图片统一放 `figures/` 并引用同目录文件。
- `main.pdf` 必须由整理后的 `main.tex` 编译得到。

## 润色范围
- 只修复解析噪音：页眉页脚重复、跨页断句断行、断词连字符、明显 OCR 误识别、公式乱行与括号不配平、跨页表格结构断裂。
- 按原论文结构恢复 section 层级，保留公式/图/表/引用顺序和 label/ref/cite 关系。

## 边界
- 不改事实、数值、单位、符号、结论强度、引用编号和作者措辞。
- 不凭记忆补写 MinerU 未识别出的内容。
- 直接编辑 `main.tex`，不动原 PDF 或 citation 文件。
