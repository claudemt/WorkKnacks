# 项目工作台

## 打开项目

点击“打开项目文件夹”，在系统文件选择窗口中选择本地目录。需要新目录时，可以直接在该窗口中创建文件夹后选择它。

工作台按文件夹浏览：双击文件夹进入，点「⬆ 返回上级」回到上级目录，双击文件用系统默认程序打开。跳过 `.workknacks` 与隐藏项。已经记录为处理结果的文件不会再次显示为输入文档。

## 文档操作

每个文档右侧有四个操作：

- **翻译**：选择翻译供应商和目标语言
- **转写**：选择转写供应商，加载并导出云录制
- **解析**：选择解析供应商，将文档转换为可编辑内容
- **AI 润色**：选择对应 Skill 后进行多轮对话

翻译、转写和解析的结果直接写入源文件所在目录。翻译结果使用 `-翻译` 后缀，转写结果使用 `-总结` 后缀，解析结果由解析供应商生成（图片统一放在源文件所在目录的 `images/` 下）。

完成后，文档列表和项目汇总会自动刷新。

## 项目状态

工具在项目目录下使用 `.workknacks/` 保存状态：

- `state.json`：处理状态、输出路径和错误信息
- `progress.json`：翻译断点
- `ai-logs/`：AI 润色记录

`.workknacks/` 不参与文档扫描。
