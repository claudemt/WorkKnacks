# WorkKnacks 帮助

WorkKnacks 把一个普通文件夹当作文献库。左边处理文件，右边保留项目 AI 对话；大多数时候只需要围绕论文内容工作，不必反复调整参数。

## 先认识主界面

顶部几个按钮负责项目本身：

- **打开项目**：选择一个文件夹作为当前文献库。以后 PDF、笔记、解析稿和译文都留在这个文件夹里。
- **上级**：从当前子目录返回上一层。
- **刷新**：重新读取磁盘和 AI 会话。你在资源管理器里手动复制了文件后，点它即可同步界面。
- **批量**：一次选多篇 PDF 做信息识别、总结或 BibTeX 导出。列表支持 Ctrl 多选、Shift 连选和全选。
- **设置**：配置 MinerU 和翻译服务。第一次使用解析或翻译前通常只需配置一次。
- **帮助**：打开本说明。

文件右侧的按钮只保留高频动作：

- PDF 的 **查看** 直接打开原文；**信息** 识别或修改题名、作者、年份、DOI 等；**翻译** 打开解析/翻译窗口；**AI** 把文件交给右侧项目 AI。
- Markdown 的 **查看** 用浏览器渲染；**编辑** 进入边写边预览；**AI** 把笔记交给项目 AI。
- 已整理的文献文件夹可以 **进入** 浏览，也可以 **编辑** 重新指定主 PDF 并修改条目信息：已登记的主 PDF 会直接载入当前在用的数据，需要时再手动重新识别；**笔记** 会在 `notes/` 下新建 `note01.md`、`note02.md`……并立即打开编辑。
- 其它文档至少提供 **查看**。选中文件或文件夹即可用键盘快捷键操作；双击名称也可以直接打开。

常用快捷键（选中文件/文件夹后有效）：

- **F2**：重命名
- **Del**：删除
- **Ctrl+Z**：撤回上一步
- **Shift+Alt+C**：复制绝对路径
- **Shift+Alt+R**：在文件资源管理器中定位打开
- **F11**：切换全屏

这些操作同样出现在右键菜单里，菜单项末尾会标注对应快捷键。

2. [解析与翻译](processing.md)：怎样配置 MinerU/翻译服务，以及数学物理论文如何解析和翻译。
